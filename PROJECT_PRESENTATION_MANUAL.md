## 3. How to Deploy to GitHub Pages in 2 Minutes ($0 Cost)

This project has been configured with `base: './'` and includes an automated GitHub Actions deployment workflow.

1. Open your terminal in `K:\nexlogistics` and initialize Git:
   ```bash
   git init
   git add .
   git commit -m "feat: VYONEX v1.4 Platform (Phase 1 & 2 Completed)"
   git branch -M main
   ```
2. Create a new public or private repository named `vyonex` on your GitHub account ([github.com/new](https://github.com/new)).
3. Link and push:
   ```bash
   git remote add origin https://github.com/<YOUR-USERNAME>/vyonex.git
   git push -u origin main
   ```
4. On GitHub, go to **Settings ➔ Pages**:
   * Under **Build and deployment > Source**, select **GitHub Actions**.
5. Within 60 seconds, your site is live at:
   **`https://<YOUR-USERNAME>.github.io/vyonex/`**
